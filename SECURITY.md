# Security Policy

## Supported Versions

Current supported versions of metalX

| Version | Supported          |
| ------- | ------------------ |
| v1.x    | Yes                |
| < v0.x  | No                 |  

## Reporting a Vulnerability

Please **do not** report security issues in public issues, discussions or pull requests.

Report privately using GitHub:

1. Go to the Security tab of this repository.
2. Click Report a vulnerability.
3. Describe the problem and how to reproduce it.

Helpful details to include:

1. The metalX version and your macOS version
2. Steps to reproduce, or a proof of concept
3. What an attacker could do with it (the impact)
- **What to expect**
1. I'll acknowledge your report as soon as I can.
2. I'll investigate, keep you updated, and fix confirmed issues in a new release.
3. Once a fix is out, I'm happy to credit you in the release notes if you'd like.

Scope

In scope: metalX itself, including its installer, the Wine download and setup, and exported .app / .dmg files.

Out of scope: vulnerabilities in third-party software metalX uses, such as Wine, DXVK, DXMT, Steam or the Windows apps you run. Please report those to their own projects.
